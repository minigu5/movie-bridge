# 영화대교 브랜드 2단계: 티켓 (메일 티켓 · 발권기)

작성일: 2026-11-07 · 선행: `2026-11-07-brand-identity-design.md`(1단계, 브랜치 `brand/stage1`)

## 1. 왜

사용자가 메일 티켓에서 늘 아쉬웠던 점: "레이아웃이 자꾸 조금씩 바뀌고, 블러가 제대로 안 될 때가 있다."

원인: `lib/ticketMail.ts`는 상황에 따라 세 가지 모양으로 나간다. ① 관리자 화면 브라우저에서 미리 만든 흐린 배경 템플릿(`background_template_url`, `lib/ticketBackgroundCanvas.ts`), ② 템플릿이 없으면 포스터만 깔고 블러 없음, ③ 포스터도 못 받으면 검은 카드. 템플릿 생성도 관리자 브라우저와 포스터 화질에 좌우된다.

**첫 번째 목표: 메일 티켓이 언제나 같은 모양으로 나온다.** 그 위에 1단계 브랜드(검정 바탕, 구기 로고, 빨강 하나, Noto Sans KR)를 입힌다.

## 2. 결정된 것 (시안: 캔버스 "2단계 티켓 시안", https://claude.ai/artifact/5KE1q7AZSatxfsTSg3bzPQ)

### 메일 티켓
- 흐린 배경과 이미지 위 글자 겹치기를 **없앤다**. 검정 바탕(#0F0F10)에 위에서부터 로고 → 상태 문장 → 티켓 카드 → 안내·버튼 → 바닥글을 세로로 쌓는다. 포스터를 못 받아와도 그 칸만 비고 레이아웃은 같다.
- 맨 위: 가로형 로고(`public/brand/png/logo-horizontal-dark@2x.png`), 폭 150.
- 상태 문장(점 없음): 확정 "예매가 확정되었어요", 대기 "입금을 기다리고 있어요", 변경 "좌석이 바뀌었어요", 취소 "예매가 취소되었어요"(회색).
- 티켓 카드(#18181A, 둥근 16, 테두리 없음):
  - 머리줄: 왼쪽 "입장권"(넓은 자간), 오른쪽 "판매번호 XXXXXXXX".
  - **작은 포스터**(폭 104, 선명하게) + 제목(22, 900) + "2D · 관람가". 사용자가 큰 포스터 대신 작은 것을 골랐다("리뉴얼한 김에 작은 걸로, 나중에 다시 바꾸든지").
  - 정보표: 일시 / 장소 / 팝콘(있을 때, 종류별 개수) / 결제(금액 · 상태). 첫 줄 위는 밝은 선, 나머지는 어두운 선.
  - 절취선: 점선 + 양옆 반원 홈. 홈은 테두리 없이 바탕색으로 파낸 모양이다.
  - 아래쪽: "좌석" + **좌석 번호 크게(54, 빨강)**, 오른쪽에 **기울어진 상태 도장** + "OOO 님" + 한 줄 안내.
  - 도장: 확정 "확정"(빨강), 변경 "변경"(빨강, 유효한 티켓이라서), 대기 "입금 대기"(회색), 취소 "취소"(회색, 좌석 번호도 회색에 취소선).
- 결제 대기에는 티켓 아래 **입금 안내 칸**(티켓과 같은 폭): "30분 안에 입금해 주세요 · 금액", 송금 QR(`/qr.jpeg`), 계좌와 "길게 눌러 복사". 계좌 문구는 지금 코드 값을 그대로 쓴다.
- 버튼: 흰 바탕(#F2F2F0)에 검은 글씨 "웹사이트에서 확인하기"(취소 메일에는 없음). 주황은 모두 없앤다.
- 바닥글: "영화대교 · 중강당 상영관".
- 색: 바탕 #0F0F10, 카드 #18181A, 글씨 #F2F2F0, 보조 #A1A1A6·#8E8E93, 선 #2A2A2E, 빨강 #E0443B. 빨강은 로고의 "화" 점, 좌석 번호, 확정·변경 도장에만 쓴다.

### 발권기 (`app/print/page.tsx`)
- **입력 화면**: 검정 바탕, 가로형 로고, "현장 발권", "예매한 티켓을 영수증으로 뽑아요.", 학생/교직원 선택(고른 쪽 흰 바탕), 학번·이름 입력(높이 58), 흰 "티켓 출력하기" 버튼. 주황 없음.
- **영수증**(72mm 흑백 감열): 검정 한 가지 색. **흑백 로고**(빨간 점도 검정) → "입장권" + 출력 시각 · 현장 발권 → 점선 → 제목 · 관람가 → 상영/장소/예매자 + 오른쪽 큰 관람석 → 점선 → 팝콘 수령 → 안내 상자(존댓말: "1인 1매 한정 출력이에요. 잃어버리면 다시 뽑거나 팝콘을 받을 수 없어요. 팝콘 배부처에 이 티켓을 보여주세요.") → 바코드 → "대구과학고등학교 영화대교". 지금의 Code39 바코드 렌더러는 그대로 쓴다.

## 3. 비목표
- 웹사이트 예매 화면, 관리자 화면 디자인(3단계), 승인·취소·홍보 메일의 다른 템플릿(4단계).
- 메일을 보내는 시점과 조건, 받는 사람 결정 로직(그대로).
- `movie_settings.background_template_url` 컬럼 삭제(DB는 건드리지 않는다).

## 4. 제약
- 메일 HTML은 표(table) 레이아웃과 인라인 스타일만 쓴다. flex·position은 메일 앱에서 깨진다(과거 확인됨). 반원 홈처럼 표로 못 그리는 모양은 작은 PNG를 CID로 붙이거나 표로 근사한다.
- 이미지는 지금처럼 CID 첨부, `contentDisposition: inline`(Android Gmail 첨부 표시 버그 방지).
- 포스터는 `poster_cdn_url || poster_url`을 `fetchSafeImage`로 받는다. 실패하면 포스터 칸을 같은 크기의 빈 칸으로 둔다.
- 메일 본문 글꼴: Noto Sans KR을 먼저 지정하고, 못 쓰는 앱을 위해 Apple SD Gothic Neo·맑은 고딕을 뒤에 둔다.
- 영수증 프린터는 흑백이다. 영수증에는 회색이나 빨강을 쓰지 않는다.

## 5. 빌더에게 맡기는 것
- 반원 홈 구현 방식(PNG CID 또는 표 근사).
- HTML 생성 함수를 순수 함수로 분리해 테스트하는 방법.
- 흑백 로고 생성: `scripts/brand/build_logo.py`에 `logo-horizontal-mono.svg`(빨강을 #111111로)를 추가.
- 관리자 화면에서 흐린 배경 템플릿을 계속 만들지 여부(메일이 더는 쓰지 않으므로 생성 단계를 빼도 된다).
